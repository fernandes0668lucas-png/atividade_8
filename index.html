Netflix

1. Área de Toque Insuficiente

Usabilidade / Toque
Elemento afetado: com.netflix.mediaclient:id/2131428387
Dimensão identificada: 33dp de altura
Inserir imagem/screenshot do bug no Netflix aqui (Substitua 'src' pela imagem correspondente: netflix_bug.png)
Bug / Erro Encontrado

O item clicável selecionado no aplicativo possui uma altura de apenas 33dp, ficando abaixo do tamanho mínimo estipulado pelas diretrizes de acessibilidade (WCAG / Material Design). Isso prejudica diretamente a navegabilidade de pessoas com tremores ou limitações motoras.

Sugestão de Solução

Expandir o elemento para a dimensão mínima recomendada de 48dp × 48dp. Isso pode ser corrigido aplicando android:minHeight="48dp" na View do layout XML ou adicionando padding ao redor da área de toque sem alterar a escala do texto.

Bus2

2. Inconsistência no Rótulo (OCR)

Leitor de Tela
Coordenadas: [65,319][1203,722]
Texto Errado: "Começar a usar 0 app"
Inserir imagem/screenshot do bug no Bus2 aqui (Substitua 'src' pela imagem correspondente: bus2_bug.png)
Bug / Erro Encontrado

O rótulo de acessibilidade capturado pelo leitor de tela trocou a letra "o" pelo numeral zero ("0"), lendo o texto como "Começar a usar 0 app". Essa falha ocorre ao delegar a leitura a um sistema automatizado de OCR em imagens em vez de usar strings acessíveis de texto.

Sugestão de Solução

Definir explicitamente o rótulo de acessibilidade no código usando a propriedade contentDescription="Começar a usar o app" (Android) ou accessibilityLabel (iOS). Evitar dependência de reconhecimento de imagem para conteúdos textuais.

Caer Mobile

3. Leitura Incompleta de Unidades

Acessibilidade de Dados
Coordenadas: [0,965][219,1550]
Leitura Truncada: "0.Omm"
Inserir imagem/screenshot do bug no Caer Mobile aqui (Substitua 'src' pela imagem correspondente: caer_bug.png)
Bug / Erro Encontrado

No card que exibe os dados pluviométricos (chuvas), o leitor de tela anuncia "0.Omm" com a unidade e valores truncados/truncamento numérico, impossibilitando que pessoas cegas ou com baixa visão compreendam a métrica apresentada.

Sugestão de Solução

Atribuir uma descrição legível e por extenso na camada de acessibilidade do componente gráfico. Em vez de ler apenas os símbolos, configure a propriedade para anunciar: contentDescription="Chuva acumulada: 0 milímetros".
